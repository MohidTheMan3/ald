Files for ALD controls (temperature readings, valve control, etc.)

To control the ALD, flash ald_manual_control.ino onto the STM32 board.

To run the GUI on the control computer: python ald_gui.py (see GUI.md)

manual_gui.py and job_gui.py are the legacy Tkinter GUIs. They are kept for reference only and are not updated for the STM32 firmware.
